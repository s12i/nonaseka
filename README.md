# ノナセカ

ブラウザで遊べるミニリズムゲーム（プロトタイプ）。プロジェクトセカイのような「4レーン・タップ判定」のゲーム性を、TypeScript + Canvas + Web Audio APIのみで実装しています。

- BGMは音源ファイルを使わず、Web Audio APIでその場で合成しています（コード進行 F→G→Em→Am のアルペジオ + ベース + ハイハット/キック）。著作権フリーです。
- 譜面（ノーツ配置）はBGMのメロディラインから自動生成しているため、音とノーツが必ず一致します。

## 遊び方

- PC: `D` `F` `J` `K` キーでレーンに対応
- スマホ/タッチ: 画面をレーンごとにタップ

判定は PERFECT / GREAT / GOOD / MISS の4段階。コンボを繋いでハイスコアを狙おう。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果をローカルで確認
```
